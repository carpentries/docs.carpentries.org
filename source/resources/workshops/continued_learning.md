# Continuing Education Resources for Learners


* [Exercism](https://exercism.org/): Free website for working on coding literacy.
* [stackoverflow](https://stackoverflow.com/questions): Open forum to ask questions and search for answers
* [Alliance for Data Science and AI](https://alliance4datascience.ai/): Non-profit focusing on continuing education, offering community events like hackathons, practice opportunities, one-off workshops, and more!
* [sandbox.bio](https://sandbox.bio/tutorials/carpentries-python-inflammation): Practice Carpentries Programming with Python exercises in an interactive environment.
